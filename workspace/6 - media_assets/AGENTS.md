# Workspace: Media Assets

## Purpose
This folder stores reusable media and brand assets used across the business.

## Inheritance
- Inherit all root and workspace-layer rules automatically.

## Rules
- Keep logos, identity assets, reusable images, videos, and templates here.
- If an asset belongs only to one project, consider storing it in that project instead.
- Organize every new media file under a `YYYY/MM` folder based on the date it is added, using a zero-padded month such as `2026/07`.
- Reuse the year and month folders when they already exist; create only the missing folders before placing the media file inside.

## Routing
- Use this folder for shared assets rather than strategy or project notes.
