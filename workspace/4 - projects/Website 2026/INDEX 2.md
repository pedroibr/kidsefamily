## Process

O projeto é produzido nesta ordem: `sitemap/` define planejamento, templates, páginas e macro-seções; `wireframes/` expande cada página em texto; `style-guide/design.md` consolida o sistema visual; `cms/` mantém post types; WordPress/GenerateBlocks recebe a implementação aprovada.
