# Website 2026 Wireframes

## Purpose

Manter o conteúdo e a direção de display das páginas listadas no sitemap.

## Inheritance

Seguir as regras do root, do workspace e do projeto Website 2026.

## Rules

- Um Markdown por página canónica.
- Usar o template e a sequência do sitemap.
- Declarar `sectionType` e `layoutId` em cada seção.
- Não criar post types aqui; eles vivem em `../cms/`.
- Não incluir markup Gutenberg, CSS ou conteúdo não aprovado.

## Routing

- Institucionais: `institutional/`.
- Hubs: `hubs/`.
- Serviços: `services/`.
- Landing pages: `landing-pages/`.
- Skill local: `../skills/wireframe-skill.md`.
