# Blog Pages

Artigos, guias, FAQs, comparações e checklists. Cada documento deve indicar o serviço ou lead magnet que apoia e incluir uma ligação interna principal para a especialidade mais relevante.

Os dez ficheiros Markdown na raiz desta pasta são os primeiros rascunhos canónicos selecionados da referência. Estão marcados como `status: draft`, em português de Portugal, e cada um contém exatamente uma ligação interna de especialidade para revisão editorial e clínica.

`references/Derivados/` contém uma exportação de referência com 103 textos de artigo ainda não publicados, para filtragem e adaptação futura.
