# Implementation Skill

## Objetivo

Construir no WordPress apenas o que já tem sitemap, wireframe e Design MD suficientemente aprovados.

## Deve fazer

1. confirmar a página e o template no sitemap;
2. confirmar conteúdo, conexões e estado do wireframe;
3. consultar o Design MD e referências GenerateBlocks;
4. implementar com blocos nativos sempre que possível;
5. verificar grid, container, responsive, semântica, CTA e acessibilidade;
6. registrar alterações, desvios e estado de produção.

## Não deve fazer

- alterar globalmente classes, cores ou templates sem pedido explícito;
- usar HTML quando os blocos nativos resolvem a estrutura;
- tratar uma implementação visual como substituta do wireframe.
