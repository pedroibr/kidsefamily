# Website Wireframes

Esta pasta contém os wireframes textuais em Markdown que servem como fonte de verdade para as páginas do website.

## Estrutura

- `institutional/`: wireframes de páginas institucionais.
- `hubs/`: wireframes de páginas agregadoras, como Blog e Especialidades.
- `services/main/`: wireframes de serviços principais.
- `services/subservices/`: wireframes de subserviços e páginas por audiência ou modalidade.
- `landing-pages/`: wireframes de lead magnets, campanhas e páginas de audiência.
- [Sections Library — localização atual](../../../../../cristianemartins/workspace/4%20-%20projects/Website%202026/skills/wireframe/references/sections-library/README.md): famílias reutilizáveis, opções, presets e referências visuais migradas para a skill local do projeto Cristiane Martins.
- Os documentos de páginas nesta pasta usam a Sections Library como referência; não duplicar aqui os documentos das famílias.
- `_template.md`: modelo de criação.

Media não é duplicada nesta pasta: a fonte oficial fica em `workspace/6 - media_assets`.

O processo de produção está em [`../skills/site-workflow/SKILL.md`](../skills/site-workflow/SKILL.md). O sitemap define a sequência macro de cada wireframe; o Design MD em [`../style-guide/design.md`](../style-guide/design.md) define regras visuais. Conteúdos repetíveis ficam em [`../post-types/`](../post-types/INDEX.md); referências técnicas de WordPress/GenerateBlocks ficam em [`../references`](../references/README.md).

Cada ficheiro deve ter frontmatter completo e uma secção `Page Connections`, conforme o `AGENTS.md` do projeto.
