# Workspace: Clients

## Purpose
This folder is optional and should be used only if the business needs external client or account contexts inside the same root.

## Inheritance
- Inherit all root and workspace-layer rules automatically.

## Rules
- Do not assume this folder is active by default.
- If activated, each child folder should add only client-specific context.

## Routing
- Keep this folder empty or minimal until the business model proves it is needed.
