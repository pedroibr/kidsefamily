# Skill References

Esta pasta contém contratos reutilizáveis pelas skills locais. Não contém páginas nem copy final.

- [Section Types](section-types.md): o que a secção precisa resolver, que conteúdo aceita e qual o tamanho recomendado.
- [Section Layouts](section-layouts.md): layouts estruturais, árvores de blocos e propriedades que o Wireframe pode escolher.
- Exemplos visuais anteriores: arquivados em `../../archive/section-library-visual-examples-20260824/`.

O Sitemap escolhe o `sectionType` e escreve os briefings; o Wireframe escolhe o `layoutId` e expande o conteúdo; o Style Guide fornece os tokens, classes e valores visuais.
