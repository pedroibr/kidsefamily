# Website 2026 Style Guide

## Purpose

Manter o Design MD específico da Clínica Kids e Family: tokens, tipografia, layout, componentes e classes GenerateBlocks.

## Inheritance

Seguir as regras do root, do workspace e do projeto `Website 2026`.

## Rules

- O Design MD é referência do projeto, não uma skill reutilizável.
- Registrar primeiro valores existentes; marcar propostas como não criadas.
- Preferir presets e classes globais existentes antes de criar CSS novo.
- Atualizar o Design MD quando uma classe, token ou regra for realmente implementada.
- Não guardar conteúdo de página, credenciais ou dados clínicos neste diretório.

- Arquitetura e sequências: `../SEO/sitemap.md`.
