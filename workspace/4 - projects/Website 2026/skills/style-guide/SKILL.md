# Style Guide Skill

## Objetivo

Manter um único Design MD com cores, tipografia, grids, componentes, estados e classes que tornam as páginas consistentes.

## Deve fazer

- registrar valores existentes antes de propor valores novos;
- definir uso semântico de cores, fontes, container, spacing, colunas, cards, botões, bordas e sombras;
- listar classes GenerateBlocks existentes, propostas e implementadas;
- documentar responsive, acessibilidade e decisões específicas da clínica;
- atualizar o Design MD quando uma regra for realmente aplicada.

## Não deve fazer

- guardar copy de páginas ou instruções genéricas de outros projetos;
- criar classes no site apenas por estarem documentadas;
- substituir o sitemap ou o wireframe.
