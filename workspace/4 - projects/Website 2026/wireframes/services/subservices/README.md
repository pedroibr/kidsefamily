# Subservice Pages

Páginas comerciais específicas por audiência, problema, modalidade ou percurso. Só criar quando houver intenção, oferta e CTA suficientemente distintos da página-mãe.

Na primeira versão, os quatro subserviços têm conteúdo publicado como primeira versão para revisão: Respiração oral infantil; Ortodontia infantil e desenvolvimento; Ortodontia funcional; e Ortodontia e alinhadores transparentes para adultos. Os ficheiros continuam a ser a fonte de copy e devem ser revistos clinicamente antes de qualquer refinamento final. Implantes dentários e Facetas dentárias permanecem dentro das páginas-mãe, conforme [`../../../sitemap/sitemap.md`](../../../sitemap/sitemap.md).
