# Post Types

Esta pasta contém documentos que representam tipos de post e registos de conteúdo distribuível. Eles não entram automaticamente no sitemap estrutural e pode receber novos tipos quando o projeto precisar.

- `blog/`: artigos, guias, FAQs, comparações e checklists.
- `testimonials/`: testemunhos autorizados e classificados.
- `case-studies/`: estudos de caso com contexto, processo e resultado observado.

Cada item deve indicar ligações para serviços, audiências, jornadas e locais de uso. Para criar uma página estrutural, primeiro atualizar `../sitemap/sitemap.md`.
