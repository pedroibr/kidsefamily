# Hubs

Esta pasta reúne páginas agregadoras do website. Um hub organiza e encaminha; não deve repetir em profundidade o conteúdo das páginas-filhas.

## Tipos de hub

- `blog.md`: lista artigos, guias, FAQs e clusters editoriais.
- `especialidades.md`: lista serviços principais e encaminha para subserviços, lead magnets e marcação.
- Outros hubs podem ser criados quando houver uma categoria com intenção própria e páginas-filhas suficientes.

## Regras

1. Cada hub deve ter uma intenção primária, uma descrição curta da categoria e um próximo passo claro.
2. A listagem deve apontar para páginas canónicas; não criar uma segunda página para a mesma intenção.
3. O hub deve declarar as suas ligações em `## Page Connections` e indicar os critérios de organização da listagem.
4. Prova social e estudos de caso continuam nas pastas próprias; podem ser ligados por hubs quando existir volume suficiente.
