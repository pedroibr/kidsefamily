# Website 2026 Post Types

## Purpose

Manter tipos de post e registos de conteúdo reutilizáveis para o website.

## Inheritance

Seguir as regras do root, do workspace e do projeto Website 2026.

## Rules

- Blog, testimonials e case studies são tipos de post, não páginas estruturais por padrão.
- Cada registo deve separar fonte, autorização, factos, interpretação e uso pretendido.
- Não inventar prova, resultados, credenciais ou claims clínicos.
- Atualizar conexões para serviços e páginas que usam o conteúdo.

## Routing

- Blog: `blog/`.
- Testimonials: `testimonials/`.
- Case studies: `case-studies/`.
