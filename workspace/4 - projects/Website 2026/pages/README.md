# Website Pages

Esta pasta contém os documentos Markdown que servem como fonte de verdade para as páginas do website.

## Estrutura

- `institutional/`: páginas institucionais.
- `hubs/`: páginas agregadoras, como Blog e Especialidades.
- `services/main/`: hubs e especialidades principais.
- `services/subservices/`: subserviços e páginas por audiência ou modalidade.
- `landing-pages/`: lead magnets, campanhas e páginas de audiência.
- `blog/`: artigos e clusters editoriais.
- `testimonials/`: testemunhos e registos de prova social; o nome técnico fica em inglês.
- `case-studies/`: materiais e registos de estudos de caso.
- `shared/`: blocos reutilizáveis e notas de apoio.
- `_template.md`: modelo de criação.

Media não é duplicada nesta pasta: a fonte oficial fica em `workspace/6 - media_assets`.

Referências técnicas de WordPress/GenerateBlocks ficam na pasta irmã [`../references`](../references/README.md), separadas das páginas que serão publicadas.

Cada ficheiro deve ter frontmatter completo e uma secção `Page Connections`, conforme o `AGENTS.md` do projeto.
