# Case Studies

Esta pasta reúne os materiais de estudos de caso, os registos Markdown individuais e a página pública [case-studies.md](case-studies.md).

## Como trabalhar

1. Colocar aqui o material recebido ou criar um registo a partir do modelo definido no `AGENTS.md` do projeto.
2. Classificar o caso por serviço, oferta, audiência, jornada, problema inicial, mecanismo e resultado observado.
3. Registar autorização, anonimização, limites das afirmações e origem das evidências antes de publicar.
4. Identificar onde o caso pode ser usado: página de serviço, subserviço, landing page, Início, Sobre ou artigo.
5. Declarar as ligações em `## Page Connections` e separar factos observados de interpretação ou promessa.
