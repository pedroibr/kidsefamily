# Website References

Esta pasta guarda referências técnicas e visuais para a implementação do website. Não são páginas publicáveis nem substituem os wireframes Markdown em `../wireframes/`.

## Como usar

- Preservar o markup original quando a referência for um export do WordPress/GenerateBlocks.
- Consultar esta pasta quando for necessário reproduzir uma estrutura de secção, tags, classes, atributos ou padrão de bloco.
- Ao adaptar uma referência para a Clínica Kids e Family, criar ou atualizar a página correspondente em `../wireframes/` e substituir conteúdo, links, media e classes conforme o projeto.
- Registrar origem, data de captura e finalidade de cada referência.
- Não tratar textos, imagens, URLs, IDs de blocos ou dados da referência como conteúdo aprovado para a clínica.
- Exports históricos podem conter a terminologia anterior de posicionamento; a fonte canónica atual usa “medicina dentária integrada”, conforme `../wireframes/` e `../sitemap/sitemap.md`.
