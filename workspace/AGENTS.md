# Workspace Layer

## Purpose
This folder contains the durable business workspaces. Each numbered folder is a stable area of work, not a temporary task.

## Inheritance
- Inherit all root rules automatically.
- Child folders should assume the root memory system, size ceilings, and rule-placement tests already apply.

## Rules
- Keep top-level workspace categories stable.
- If a rule affects multiple workspaces, move it up to the root.
- If a memory file here grows too much, compact it and move old detail to `archive/ARCHIVE.md`.

## Routing
- Use the numbered workspace folders as the first routing layer for all work in this business.
