# Referências do Blog

`Derivados/` é uma cópia de referência da pasta recebida em `Downloads/Derivados/`. Ela reúne **103 textos de artigo** em Markdown, cada um acompanhado, em geral, pelo contrato JSON, materiais de carrossel e indicação de imagem de capa.

Os artigos ainda não foram publicados nem convertidos em posts. A pasta será usada para filtrar temas, rever adequação clínica e editorial, evitar canibalização e selecionar os conteúdos que entrarão no plano do Blog.
